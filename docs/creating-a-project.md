# 📝 Creating a Project in Actian DataConnect: Step-by-Step Tutorial

Welcome to the comprehensive guide for creating a project in **Actian DataConnect**! This tutorial will walk you through every step required to set up a new project, from launching the application to finalizing your project details. Each action is clearly documented, and key screenshots are included to ensure you know exactly what to expect at every stage.

---

## 📋 Prerequisites

Before you begin, ensure you have the following:

- **Actian DataConnect Studio** installed on your system
- Access to a workspace directory (e.g., `C:/Actian/DataConnect/workspace`)
- Basic familiarity with navigating Windows applications

> **Note:** No prior experience with Actian DataConnect is required. This guide is suitable for beginners.

## ## Starting a New Project

23. **Wait for the application to load.**
    - The splash screen appears while the application initializes.

24. **View the "Create a DataConnect Project" introduction.**
    - The tutorial introduces the project creation process.
    <img src="https://videotodocs.fra1.cdn.digitaloceanspaces.com/projects/screenshots/20de9f51-952f-427a-9078-25c82005fb48/frame_0024.png" />

25. **Open the File menu.**
    - Click **File** in the top menu bar to begin creating a new project.

26. **Navigate to New > DataConnect Project.**
    - Hover over **New** and select **DataConnect Project** from the submenu.

27. **Highlight DataConnect Project.**
    - Ensure **DataConnect Project** is highlighted before proceeding.
    <img src="https://videotodocs.fra1.cdn.digitaloceanspaces.com/projects/screenshots/20de9f51-952f-427a-9078-25c82005fb48/frame_0027.png" />

28. **Confirm selection in the menu.**
    - The tooltip "Create a DataConnect project" appears, confirming your selection.

29. **Select DataConnect Project.**
    - Click **DataConnect Project** to launch the project creation wizard.
    <img src="https://videotodocs.fra1.cdn.digitaloceanspaces.com/projects/screenshots/20de9f51-952f-427a-9078-25c82005fb48/frame_0029.png" />

## ## Alternative Project Creation Methods

30. **Select Templates folder.**
    - In the Project Explorer, select the **Templates** folder.

31. **Rename or select Templates.**
    - The folder name becomes editable, allowing you to rename or confirm selection.
    <img src="https://videotodocs.fra1.cdn.digitaloceanspaces.com/projects/screenshots/20de9f51-952f-427a-9078-25c82005fb48/frame_0031.png" />

32. **Open the New dropdown from the toolbar.**
    - Click the **New** button (blank page icon) to open the creation menu.

33. **Review creation options.**
    - The dropdown displays options for creating various project types.

34. **Select DataConnect Project from the menu.**
    - Highlight and select **DataConnect Project** from the dropdown.
    <img src="https://videotodocs.fra1.cdn.digitaloceanspaces.com/projects/screenshots/20de9f51-952f-427a-9078-25c82005fb48/frame_0034.png" />

35. **Confirm selection in the New menu.**
    - The description "Create a DataConnect project" appears below the highlighted option.

36. **Open the context menu in Integration.**
    - In the Integration pane, open the context menu and review available options.
    <img src="https://videotodocs.fra1.cdn.digitaloceanspaces.com/projects/screenshots/20de9f51-952f-427a-9078-25c82005fb48/frame_0036.png" />

37. **Right-click Templates for New options.**
    - Right-click the **Templates** folder and navigate to **New > DataConnect Project**.

38. **Hover over DataConnect Project.**
    - Ensure the tooltip "Create a DataConnect project" is visible.

39. **Select Data Profile (alternative).**
    - Optionally, select **Data Profile** from the New submenu.
    <img src="https://videotodocs.fra1.cdn.digitaloceanspaces.com/projects/screenshots/20de9f51-952f-427a-9078-25c82005fb48/frame_0039.png" />

40. **Highlight DataConnect Project again.**
    - Confirm the selection of **DataConnect Project** in the context menu.

## ## Naming and Describing Your Project

41. **View the instructional slide.**
    - The tutorial introduces the step for naming and describing your project.
    <img src="https://videotodocs.fra1.cdn.digitaloceanspaces.com/projects/screenshots/20de9f51-952f-427a-9078-25c82005fb48/frame_0041.png" />

42. **Read the section header.**
    - The slide reinforces the importance of naming and describing your project.

43. **Open the New DataConnect Project wizard.**
    - The wizard prompts you to enter a **Project name** and choose a location.
    <img src="https://videotodocs.fra1.cdn.digitaloceanspaces.com/projects/screenshots/20de9f51-952f-427a-9078-25c82005fb48/frame_0043.png" />

44. **Check "Use default location".**
    - By default, the location is set to `C:\Actian\DataConnect\workspace\DC_Sample`.

45. **Uncheck "Use default location" if needed.**
    - If you want to specify a custom location, uncheck the box.

46. **Enter the project name.**
    - Type `DC_Sa` (or your desired name) in the **Project name** field.
    <img src="https://videotodocs.fra1.cdn.digitaloceanspaces.com/projects/screenshots/20de9f51-952f-427a-9078-25c82005fb48/frame_0046.png" />

47. **Complete the project name.**
    - Enter the full name, e.g., `DC_Sample`.

48. **Review location settings.**
    - If "Use default location" is unchecked, the location field is visible but not editable.
    <img src="https://videotodocs.fra1.cdn.digitaloceanspaces.com/projects/screenshots/20de9f51-952f-427a-9078-25c82005fb48/frame_0048.png" />

49. **Check "Use default location" to lock the path.**
    - The location field becomes disabled and shows the default path.

50. **Address location warnings.**
    - If prompted, ensure a valid project location is specified.
    <img src="https://videotodocs.fra1.cdn.digitaloceanspaces.com/projects/screenshots/20de9f51-952f-427a-9078-25c82005fb48/frame_0050.png" />

51. **Specify a custom location if required.**
    - Uncheck "Use default location" and use the **Browse...** button to select a directory.

52. **Open the file/folder selection dialog.**
    - Click **Browse...** to choose a custom location.

53. **Confirm the Browse action.**
    - The file selection interface appears; select your desired folder.
    <img src="https://videotodocs.fra1.cdn.digitaloceanspaces.com/projects/screenshots/20de9f51-952f-427a-9078-25c82005fb48/frame_0053.png" />

54. **Return to the wizard and review details.**
    - Ensure the project name and location are correct.

55. **Click "Next >" to proceed.**
    - The **Next >** button becomes active; click it to continue.
    <img src="https://videotodocs.fra1.cdn.digitaloceanspaces.com/projects/screenshots/20de9f51-952f-427a-9078-25c82005fb48/frame_0055.png" />

56. **Enter a project description.**
    - In the **Project Description** field, type `Sample project for demo purpose.`

57. **Review the description entry.**
    - The description field is highlighted, and you can edit as needed.

58. **Ensure the "Finish" button is enabled.**
    - Once all required fields are filled, the **Finish** button becomes active.
    <img src="https://videotodocs.fra1.cdn.digitaloceanspaces.com/projects/screenshots/20de9f51-952f-427a-9078-25c82005fb48/frame_0058.png" />

59. **Review all details before finishing.**
    - Confirm the project name, location, and description.

60. **Click "Finish" to create the project.**
    - The wizard closes, and your new project is created.
    <img src="https://videotodocs.fra1.cdn.digitaloceanspaces.com/projects/screenshots/20de9f51-952f-427a-9078-25c82005fb48/frame_0060.png" />
